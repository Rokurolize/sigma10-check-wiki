# KB-11 — JP credit-module localization supplement missing from the candidate (3law-pride class)

- **Class:** A. Theme defect, file-provable
- **Detection cost:** cross-file diff
- **Provability:** FILE-PROVABLE
- **Status:** adopted
- **Basis:** owner-inspection, static-diff
- **Dedupe key:** credit module CSS / JP localization supplement absent in the candidate while production carries it / production-vs-candidate credit selector diff (NONE class)
- **Support:** 2 (owner-inspection, static-diff)
- **Evidence source:** R/KNOWLEDGE-SEED-INVENTORY.md (compiled 2026-11-17 from the GOSIGN2 review reports and coordinator adjudications named there).

## Mechanism

EN themes target the info module; SCP-JP renders credits through its own credit
module (`credit:start` family), whose DOM needs JP-side CSS rules to reach the
original's design intent. The production JP version of a theme family carries a
localization supplement: extra rules styling the credit module's DOM. A port
candidate that carries ZERO rules for the credit-module DOM, while the
production JP theme carries the supplement, renders its credit block unstyled or
wrongly styled after migration even though every source check on includes
passes. (This entry is seeded from a parallel review of the 3law family, as
tasked; the GOSIGN2 reports themselves cover the sibling residue in KB-12 and
the AGENTS.md section 9 info-credit audit.)

## Static detection

Extract the credit-module selector set from the production JP theme file
(selectors mentioning the credit module's classes/ids, e.g. the `#credit` /
`.credit` / modal and rate sub-selectors the production file styles) and the
same set from the candidate file. Zero overlap, where the production file has a
non-empty supplement, is the defect signal. Diffing the two files'
credit-related rule blocks shows exactly which rules are missing.

## Confirmed instances

Confirmed set from the parallel repo review (full record in the
sigma10-review-20261117 LEDGER on the VM; every one of these rows reads
production-complete in the start table): 3law-pride, 3lawcracked,
the-other-side, travellers-book. Convergent problem row: share-future-community
(dropped its credit CSS entirely; bare sigma-plus include). Adjacent campaign
evidence: the info-credit audit's NEEDS-SUPPLEMENT verdicts for classic,
flopstyle-dark, wikifot (AGENTS.md section 9, archive
`info-credit-20261113/RESULT-L1/L2/L4/L6`).

## False positives and disposition

Themes whose original design does not use the credit module's styled DOM, and
Sigma-10 itself (KB-53, excluded from credit-furniture waves), are not charged.
Confirm the production file actually carries a supplement before charging the
candidate.

## Fix

Port the production supplement's rules into the candidate, adapted to the
candidate's variable names, so the JP credit module reaches the original's
design intent.

## Amendment (2026-11-17, documentation-pass taxonomy review): the in-place correction form

This pattern's charge is an absence: zero candidate rules for the
credit-module DOM where the production counterpart carries a
supplement. One shape produces that absence reading while the
localization was in fact applied: the theme's own inherited rules are
corrected to the frozen JP component markup instead of a supplement
block being added. Index instance: sodium. The theme's inherited
rule addresses the credit anchor as `.creditButton p a` (the EN
credit markup nests the anchor in a paragraph); the JP credit
component (credit:start-preview) emits the anchor as a direct child
of .creditButton, so the inherited selector can never match on JP.
The candidate corrects the selector to `.creditButton > a` on the
theme's own rules (theme:sodium-jp: correction blocks at L313-316,
L327, L332, L441 ff., under porter comments stating the ground). No
basalt-form supplement block exists, which is correct here: the theme
already carried the rules; only their selector form was EN-shaped.

Detection consequence: before recording a NONE-class absence for a
theme whose original carries credit-module rules of its own, diff the
candidate's credit selectors against the original's. A selector-form
delta on otherwise-carried declarations (same properties, retargeted
selector) is the correction form: record the theme as T7 applied in
place, not as a missing supplement. The two-channel rule applies
unchanged. Disposition: not charged under this pattern; the theme's
explanation records the correction in its credit section.
