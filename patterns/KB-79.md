# KB-79 — Documentation exhibits leaked into the delivered code block

- **Class:** A. Theme defect, file-provable
- **Detection cost:** cross-file diff
- **Provability:** FILE-PROVABLE
- **Status:** adopted
- **Basis:** static-diff
- **Dedupe key:** exhibit leak / small :root customization exhibits appended inside the delivered code block while their prose headings stand bare in the body / body-heading-without-exhibit plus tail-exhibit plus brace-depth scan
- **Support:** 2 (static-diff)
- **Evidence source:** R/review-scout/BATCH-RFIX20.md proposal 1 (winddew-in-hand-jp W2), BATCH-RFIX5.md (gp-refresh item 59).

## Mechanism

Documentation exhibits (small `:root` customization examples) get
appended inside the delivered code block while their prose headings stay
bare in the body. The delivered stylesheet then carries example values
that were meant to be copied, not shipped, and the body headings teach
nothing. A brace-depth scan of the delivered block ends above 0, which is
the mechanical tell; the same shape was found by a different route in the
gp-refresh package.

## Static detection

Flag a candidate where (a) body headings have no exhibit under them,
(b) exhibit-shaped `:root` blocks sit at the delivered block's tail, and
(c) the delivered block's brace depth ends above 0. Confirm the exhibit
blocks are documentation examples in the original, not part of the
delivered stylesheet.

## Confirmed instances

winddew-in-hand-jp (flag W2), gp-refresh (item 59, found by a different
route). The recipe ties the two routes to one class.

## False positives and disposition

A delivered `:root` override block that belongs to the theme's own
design is not an exhibit. KB-67 covers an exhibit dropped or replaced
without a ground; this pattern is the inverse (an exhibit living in the
wrong channel). A depth-end above 0 that is the original's own damage is
KB-71.

## Fix

Move the exhibit blocks out of the delivered code block back under their
body headings, and restore the delivered block's brace balance. Record
the move in the explanation's Structure section.
