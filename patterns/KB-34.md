# KB-34 — Preview-notice row clipping / overprint at narrow widths

- **Class:** C. Cross-cutting, not a defect
- **Detection cost:** cross-file diff
- **Provability:** FILE-PROVABLE
- **Evidence source:** R/KNOWLEDGE-SEED-INVENTORY.md (compiled 2026-11-17 from the GOSIGN2 review reports and coordinator adjudications named there).

## Mechanism

The check wiki's preview chrome inserts a notice row above the page. At ≤375/320
(and at 768, where the sidebar and the notice overlap), the row clips at the
left or overprints, identically for every theme, because the chrome's own layout
assumes the production header geometry.

## Static detection

Disposition by location: clipping/overprint confined to the preview-notice row
(the wiki chrome strip, not the theme's header or content) is cross-cutting.
Compare against the baseline page's notice row; identical clipping there settles
it.

## Confirmed instances

Named in AGENTS.md section 3 T2 environment-layer lines; per-theme notes across
RENDER-A..H and RERUN16 (classic and flopstyle: 768px sidebar x preview-notice
overlap hiding notice text, RENDER-ROWS-1).

## False positives and disposition

Clipping of the theme's OWN header elements at the same widths is KB-24. The two
are distinguished by which element clips, which a single screenshot crop
settles.

## Fix

None.
