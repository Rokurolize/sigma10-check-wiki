# KB-19 — Follow-up delta unincorporated (T4 follow-up half)

- **Class:** A. Theme defect, file-provable
- **Detection cost:** needs live probe
- **Provability:** FILE-PROVABLE
- **Evidence source:** R/KNOWLEDGE-SEED-INVENTORY.md (compiled 2026-11-17 from the GOSIGN2 review reports and coordinator adjudications named there).

## Mechanism

The original theme keeps evolving after the port's reference revision. Upstream
hunks of kind `css_rules` / `css_vars` / `includes` / `scripts` / `body_text`
that are display-affecting and never incorporated leave the JP candidate
rendering an older design than the original it claims to port.

## Static detection

Run the follow-up exactly as AGENTS.md section 5: `uv run
scripts/wd_revisions.py diff <original page URL> --from <reference rev>` (target
argument required). Exit 0 with 変更なし means current. Classify each hunk by kind;
only the five content kinds above can fail the theme, and only if
display-affecting.

## Confirmed instances

The T4 follow-up halves across REPORT-GOSIGN2-LOCALIZE-A/B and S2-A..F
(per-theme diff records). Settled non-follows: Generic Space (28 to 32) and
Turbo Vision (53 to 54) upstream moves are NO-FOLLOW, bulk-only.

## False positives and disposition

`fonts` / `body_url_only` / `import_url` (AutoLocalize) moves are not followed.
Phase 17/22 records cover the 44 Stage-1 rows only; their absence for Stage-2
slugs is not a finding.

## Fix

Incorporate the display-affecting hunks into the candidate and advance the
recorded reference revision (改訳 line mechanics per AGENTS.md section 5).
