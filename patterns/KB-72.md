# KB-72 — Documented default contradicts the shipped variable

- **Class:** A. Theme defect, file-provable
- **Detection cost:** cross-file diff
- **Provability:** FILE-PROVABLE
- **Status:** adopted
- **Basis:** static-diff
- **Dedupe key:** documentation default / a デフォルト値 line or specimen sentence stating a default (font name, size) that differs from the shipped :root variable or from the variables the specimen describes / doc-line vs variable-value census
- **Support:** 2 (static-diff)
- **Evidence source:** R/review-scout/BATCH-MPURE12.md proposal 3, BATCH-U5.md proposal 1.

## Mechanism

A theme's usage documentation states a default (a font name, a size) in
prose, while the shipped `:root` variable carries a different value; or a
specimen line ("本文フォントはXです") names a face the body/mono variables
do not name and nothing loads. The prose renders for readers and states a
falsehood about the delivered theme. The classifier lands these blocks in
HEADERVAR/residue because it has no signature comparing prose defaults
to variable values.

## Static detection

In each candidate, extract documentation lines stating a default
(`デフォルト値`, "default", `本文フォントは…`) and compare the named value
against the `:root` definitions and the loaded font set in the same file.
A stated value with no matching variable, or a variable that differs from
the documented value, is the hit. Include specimen lines that name a
face: check the face against the variables the specimen describes and
against loads.

## Confirmed instances

foxtrot (FIX3-A2 item 4: documentation default differs from the shipped
variable), walk-in (specimens claim a face the body/mono variables do not
name and nothing loads).

## False positives and disposition

A documented default that matches the variable is not a hit. A difference
that is itself the documented port adaptation, with the ground recorded,
is dispositioned, not charged. Untranslated visible text is KB-18, not
this pattern (the default line may be translated and still false).

## Fix

Correct the prose to the shipped value, or change the variable to the
documented value where the prose states the intended design. Record which
side was authoritative in the explanation.
