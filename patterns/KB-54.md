## Mechanism

Some live foreign includes have no JP counterpart at all: the cross-wiki include
resolves and renders identically from the original site, and Sigma-10 is NOT a
Sigma-9 substitute, so repointing to it would change the rendering. The include
stays foreign by ruling.

## Static detection

After KB-15's role-equivalence probe returns no verified counterpart, record the
line as this exception with the probe evidence, byte-unchanged. The test is the
failed probe, documented, not an impression.

## Confirmed instances

FIX-MECH's six (incl. opinions-broadcaster's Sigma-9 delivery via
`component:theme`, `component:acs-animation`, `component:betterfootnotes`,
`component:hoverlinks`): REPORT-GOSIGN2-FIX-MECH, AGENTS.md section 6,
supervisor adjudication FIX-P4 U4 + section 5a (state file, 2026-11-17).
