# KB-15 — Foreign include kept where a verified JP counterpart exists (pattern 1, live form); wrong-form and wrong-slug variants

- **Class:** A. Theme defect, file-provable
- **Detection cost:** needs live probe
- **Provability:** FILE-PROVABLE
- **Evidence source:** R/KNOWLEDGE-SEED-INVENTORY.md (compiled 2026-11-17 from the GOSIGN2 review reports and coordinator adjudications named there).

## Mechanism

A live `[[include :scp-wiki:…]]` / `:scpwiki:` / unprefixed include pulls the EN
component at render. Where a role-equivalent JP page exists, the JP wiki should
load the JP component (different DOM, different localization); where the include
names a form that exists only on the check wiki (unprefixed
`component:sigma-plus`, which is 404 on real scp-jp; the correct port is
`component:sigma-plus-jp`), the include silently breaks at posting.
Usage-example text naming `theme:<slug>` without `-jp` breaks every copy-paste
install the same way.

## Static detection

List all live includes in the candidate (skip `@@…@@` examples for the live
charge, but see the disposition). For each foreign or unprefixed target, probe
existence on scp-jp by fullname and test ROLE equivalence (same fullname live,
or a campaign candidate whose `local--code` delivery serves the same role,
fetched and inspected). Existence alone is not equivalence (JP
`component:audio-player` exists but is not API-compatible with the
`:snippets:html5player` dispatcher; coordinator call).

## Confirmed instances

al-slop pattern 1: unprefixed `component:sigma-plus` (exists on the check wiki,
404 on scp-jp): LOCALIZE-A row 2. flopstyle escaped examples repointed to
`:scp-jp:` forms where targets exist (FIX-MECH). The
`:scp-jp:component:sigma-plus` no-`-jp` form 404s and is wrong (AGENTS.md
section 5).

## False positives and disposition

No verified counterpart: leave byte-unchanged as a named exception (KB-54).
Escaped documentation examples are classed (i) too (checklist section 4 covers
code examples in usage sections) and are repointed only where the JP target is
verified.

## Fix

Repoint to the verified JP counterpart form for the context (check wiki
unprefixed candidate name; posting `:scp-jp:` posting name).
