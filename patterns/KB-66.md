# KB-66 — Dead prose link to a page name that will not exist on scp-jp

- **Class:** A. Theme defect, file-provable
- **Detection cost:** needs live probe
- **Provability:** FILE-PROVABLE
- **Status:** adopted
- **Basis:** live-probe, static-diff
- **Dedupe key:** prose link target / live [[[name]]] link in candidate body or documentation whose target is absent on scp-jp under that name / fullname probe plus population check, three-way disposition
- **Support:** 2 (live-probe, static-diff)
- **Evidence source:** R/REPORT-GOSIGN2-FIX5-TEXTB.md, R/REPORT-GOSIGN2-FIX5-TEXTA.md, R/REPORT-GOSIGN2-FIX5-FONTSB.md (2026-11-17); precedent R/REPORT-GOSIGN2-FIX3-B.md; charges in R/GOSIGN2-LEDGER.md section (e) class H (24 items), outcomes in R/GOSIGN2-LEDGER-SUPPLEMENT.md.

## Mechanism

A candidate's prose and documentation carry live wikilinks copied from
the branch original under the original's page names (`theme:basalt`,
`sci-fi-hub`, `wanderers:travellers-book-hub`). At posting those names
do not exist on scp-jp: the port candidates carry `-jp` names, and some
targets have no JP counterpart at all. Every reader who follows the
link hits a red link. The port re-homed the theme's code and includes
but not the links inside its text.

## Static detection

Enumerate live prose links ([[[...]]] outside @@…@@ escapes and
outside code exhibits) whose target is a page name rather than an
include or a URL. For each target, the deciding steps are external:
(1) probe the fullname on scp-jp; (2) check the campaign population
(start-themes.tsv and the canonical repo) for a `-jp` candidate of the
same name. A charge assembled from a review report's assertion alone
is not evidence: probe every target, in both directions, before
editing (see the shivering-night false positive below).

## Confirmed instances

Ledger class H, 24 items, all FIXED (supplement). Named: shivering-night
(theme:basalt and theme:parallel probed 404, repointed to the -jp
candidates); starry (theme:mox, theme:shivering-night, both 404,
repointed); trauma (theme:suprematism repointed to theme:suprematism-jp);
the-track-changers (belief, theme:old-money-theme); travellers-book
(wanderers:travellers-book-hub, no JP counterpart); sci-fi (sci-fi-hub,
no JP counterpart); scpdeclassified and scplive (hub links whose CN
originals serve while the JP names 404).

## False positives and disposition

- Target probes live on scp-jp under the charged name: not a defect,
  and the link stays byte-unchanged. Worked example: shivering-night's
  theme:aero-glass and k-s-g-hub both return HTTP 200 on scp-jp with
  no checker link-target-missing warning, and the charging ledger's
  suggested replacement theme:aero-glass-jp does not exist. The
  premise of a dead-link charge is falsifiable and must be falsified
  or confirmed by probe, never inherited.
- Sibling-candidate targets carrying -jp names that 404 only because
  nothing is posted yet are the batch-posting class (all candidates
  post at once), not this pattern.
- Links inside @@…@@ escapes or code exhibits document syntax; they
  are not live links (cf. the KB-59 exhibit shape).
- Usage-example include text naming theme:<slug> without -jp is the
  KB-15 include-form shape, not this pattern. Dead asset URLs are
  KB-02, not this pattern.

## Fix

Three-way, by probe outcome: (a) a -jp candidate exists in the
population: repoint to it, preserving the link label and the
original's spacing. (b) No JP counterpart, but the original-branch
page serves: replace with an explicit external link to that page
with a Japanese label and an untranslated-content note (FIX3-B
precedent; applied by FIX5-FONTSB to scpdeclassified and scplive).
(c) Nothing serves anywhere: convert to plain text with a
translator's note preserving the original page name (FIX5-TEXTB:
travellers-book and sci-fi hubs).
