# KB-74 — Original module selectors lost in delivery consolidation

- **Class:** A. Theme defect, file-provable
- **Detection cost:** cross-file diff
- **Provability:** FILE-PROVABLE
- **Status:** adopted
- **Basis:** static-diff
- **Dedupe key:** module selector survival / an original [[module CSS]] block's distinctive top-level selectors or custom properties that appear nowhere in the candidate after its modules were consolidated / per-side selector-set census across all modules
- **Support:** 3 (static-diff)
- **Evidence source:** R/review-scout/BATCH-MPURE2.md proposal 1, BATCH-RDISP2.md proposal 2, BATCH-RDISP3.md proposal 2, BATCH-RDISP9.md proposal 2, BATCH-U2.md proposal 2.

## Mechanism

When a port consolidates an original's N `[[module CSS]]` blocks into one
delivered block, the topology pass labels the moves DELIVERY-MOVE on
main-block similarity. Minor modules pair by kind, so a selector set
dropped from a minor module fires no block: distinctive rules (a rating
module's variables, a rate-widget gradient, a single `.logo` rule inside a
~900-line block) vanish silently while the move label asserts a clean
relocation. A single-module candidate with body prose mapped into its CSS
module produces the same false pairing.

## Static detection

Extract each original module's top-level selectors and custom properties
and each candidate block's, across ALL modules and blocks per side. Report
original selectors with zero candidate hits as dropped-selector candidates
for adjudication, after subtracting what a resolved base supplies. Where
the candidate has one module and no code block, treat DELIVERY-MOVE blocks
whose original side is body prose as body-absence candidates (KB-67)
instead of moves. Require whole-block content similarity before firing
DELIVERY-MOVE, and prefer same-channel pairing before cross-channel
matching.

## Confirmed instances

bulgunae (dropped rating-module variables and rate-widget gradient
labeled DELIVERY-MOVE), cobalt (single `.logo` rule under DELIVERY-MOVE;
37 blocks mislabeled by cross-channel pairing), betwixt and old-money
(original head module's inline rules vanishing when @imports moved into
the code block).

## False positives and disposition

A selector supplied by the resolved base is not dropped. A selector that
moved to a different channel but survives with identical declarations is
a relocation, not a drop (KB-14). Re-emitted whitespace-only drift is not
a selector loss.

## Fix

Restore each dropped selector in the candidate's delivered block, or
record a named disposition if the rule was intentionally retired. Never
let a DELIVERY-MOVE label stand as proof that no selector was lost.
