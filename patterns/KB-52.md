# KB-52 — amethyst-v2: no candidate can be produced

- **Class:** F. Named exception / standing disposition
- **Detection cost:** pure grep
- **Provability:** FILE-PROVABLE
- **Evidence source:** R/KNOWLEDGE-SEED-INVENTORY.md (compiled 2026-11-17 from the GOSIGN2 review reports and coordinator adjudications named there).

## Mechanism

amethyst-v2 is a g2lighter component-family theme: its design is a component
set, not a standalone theme page, so no single candidate page can be produced
for it. It is excluded from the pass population by name.

## Static detection

None: the absence of `pages/theme:amethyst-v2-jp.txt` IS the state. Any sweep
must carry it as EXCEPTION, never as a missing file to invent. (Its ledger rows
exist under three spellings: blank exception rows in T1/LOCALIZE parts,
`theme:amethyst-v2-jp` NOT-RUN in the render parts; LEDGER-POPULATION-CHECK
section 5.)

## Confirmed instances

REPORT-GOSIGN2-T1-BASELINE (row 144 EXCEPTION), AGENTS.md section 6.

## False positives and disposition

Named exception, excluded from the pass population.
