# KB-43 — Interwiki-frame stylesheet 404 from shared styleFrame.html infrastructure

- **Class:** D. Environment-layer
- **Detection cost:** pure grep
- **Provability:** FILE-PROVABLE
- **Evidence source:** R/KNOWLEDGE-SEED-INVENTORY.md (compiled 2026-11-17 from the GOSIGN2 review reports and coordinator adjudications named there).

## Mechanism

The `url-https//…` interwiki-frame stylesheet 404 originates in the shared
`styleFrame.html` infrastructure that every page using the interwiki frame
loads, not in any candidate's CSS or includes.

## Static detection

Disposition by URL shape: the malformed `url-https//` stylesheet line is
infrastructure on sight. It is distinct from KB-29 (the frame hidden by theme
rules) and KB-07 (the candidate's include defects): neither the include set nor
the theme's rules produce this line.

## Confirmed instances

AGENTS.md section 3 T2 environment-layer lines.

## False positives and disposition

A 404 on a candidate-own stylesheet is KB-05/KB-47 territory; check the URL's
owner.

## Fix

None.
