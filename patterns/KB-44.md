# KB-44 — Transient Wikidot 503 capture (http.cat + hidden-* signature)

- **Class:** E. Capture and measurement artefact, not a result
- **Detection cost:** pure grep
- **Provability:** FILE-PROVABLE
- **Evidence source:** R/KNOWLEDGE-SEED-INVENTORY.md (compiled 2026-11-17 from the GOSIGN2 review reports and coordinator adjudications named there).

## Mechanism

Wikidot intermittently serves a 503 page (the http.cat placeholder) instead of
the theme page. render_check dutifully measures the 503 page: its only
runtime-hotlink host is `http.cat` and every content element is missing,
producing a block of `hidden-*` errors (hidden-footer, hidden-license,
hidden-login, hidden-pageContent, hidden-rate) plus a header-link error. The
signature is the 503 page's shape, not the theme's.

## Static detection

Read the summary text: a capture whose ONLY runtime-hotlink host is `http.cat`
AND which carries a block of `hidden-*` errors is a transient 503, not a result.
Disposition the whole capture, re-run that target once, and use the fresh
capture. Partial shapes (http.cat as one host among others, no hidden-* cluster)
are NOT this pattern (scpdeclassified-sample, starbasalt-sample in
RENDER-ROWS-G).

## Confirmed instances

ordopharm-page (chromium 1366 capture; re-run replaced it with a clean page) and
gsk-sample: RERUN16 rules and per-theme notes. Ten hidden-* clusters in the C..F
reports dispositioned as transient-503 captures in RENDER-ROWS-2
(thalassophobia-sigma, words-of-wisdom, candela, cobalt-aero-glass, construct,
emotion-division, horn, garak-the-magazine, jiha, path-of-jinin).

## False positives and disposition

A `hidden-*` line WITHOUT the http.cat-only host shape is a real signal (KB-29,
KB-30). Never disposition a single hidden line by this pattern.

## Fix

None; re-run once per target.
