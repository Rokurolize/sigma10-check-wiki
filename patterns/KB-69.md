# KB-69 — Language-bearing title artwork retired for a text title

- **Class:** F. Named exception / standing disposition
- **Detection cost:** pure grep
- **Provability:** FILE-PROVABLE
- **Status:** adopted
- **Basis:** lane-report
- **Dedupe key:** title artwork / a language-bearing image masthead replaced by a text title in the theme's own main color, with no asset carried at a new host and nothing linked / head-image absence plus text-title presence diff
- **Support:** 1 (lane-report)
- **Evidence source:** R/review-scout/BATCH-MFRAME2.md, proposal P-4 (garak masthead, 2026-11-17).

## Mechanism

An original teaches its identity with a language-bearing title image (a
masthead SVG/PNG whose lettering carries a language). Some ports replace
it with a text title set in the theme's own main color. This is a
deliberate substitution, not a KB-17 host violation (the asset is not
carried at a new host) and not the class-(ii) kept-hotlink form (nothing
is linked). Without a name, the diff shape (background/mask/color lines)
reads as an unexplained CSS-BODY cluster and each batch re-adjudicates it.

## Static detection

Diff the candidate head against the original at the reference revision:
original carries a title-image reference whose candidate has no
counterpart, while the candidate's head carries a text title colored from
the theme's own variable. The three exclusions (no new host, no live
link, no substituted asset at all) must all hold; otherwise judge under
KB-17 or KB-02.

## Confirmed instances

garak (masthead retired for a text title in the theme's main color),
reported in BATCH-MFRAME2.md P-4. The population has not been censused;
garak is the sole confirmed instance and the recipe is the instrument for
completing the set.

## False positives and disposition

A title image repointed to a JP host is KB-17, not this pattern. A dead
title image left byte-unchanged is KB-02 / KB-58. A title image kept as a
live hotlink is the class-(ii) form, not this pattern.

## Fix

No candidate edit. Record the substitution in the explanation's delivery
section: the original artwork carried language the port renders as text,
the text title uses the theme's own main color, and no asset was carried
or linked. A reviewer diffing head rules then reads a disposition, not a
drop.
