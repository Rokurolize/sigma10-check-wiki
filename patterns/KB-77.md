# KB-77 — Original variable dropped while the resolved base defines a different value

- **Class:** A. Theme defect, file-provable
- **Detection cost:** cross-file diff
- **Provability:** FILE-PROVABLE
- **Status:** adopted
- **Basis:** static-diff
- **Dedupe key:** base-variable override / a variable the original's own layer sets that the candidate's own layer is silent about while the resolved base chain defines a different value / original-override vs resolved-base value diff
- **Support:** 2 (static-diff)
- **Evidence source:** R/review-scout/BATCH-RDISP4.md proposals 1-3 (creature, darkblue, vanguard-supplement census).

## Mechanism

An original's own layer (`:root` and override blocks) sets a variable to
a value that differs from its base's. If the candidate's own layer is
silent about that variable and its resolved base chain defines a
different value, the candidate silently reverts to the base value: a
regression that presents as a disposition bundle ("lane-recorded
severity / specimen class") rather than as a charge. The same shape hits
when a disposition rests on byte-identity over named regions while a
neighboring rule drops silently, and when a duplicated load rides in an
@import-of-code-block chain that an include-based census cannot see.

## Static detection

Compare the variables the original's own layer sets against the values
the candidate's resolved base chain defines. Where the original sets a
variable, the candidate's own layer is silent, and the base differs, flag
a regression candidate. For byte-identity dispositions, also census the
full selector set of the surrounding region so a neighboring silent drop
cannot ride under an over-read identity claim. Extend duplicated-load
censuses from page-include chains to @import-of-code-block chains.

## Confirmed instances

creature (`:root` drop; base defines a different value), darkblue (two
rules between the `:is(#side-bar, #interwiki)` rules, outside the three
identity regions, carried only as CSS-BODY heuristic), and the duplicated
Noto Sans JP load in creature's @import-of-code-block chain.

## False positives and disposition

A variable the base does not define is not this pattern. A variable the
candidate sets explicitly (even to the base's value) is decided by that
declaration, not by this pattern. Extend the census to both CSS channels
and subtract the resolved base per the two-channel rule.

## Fix

Restore the original's override value in the candidate's own layer, or
record a named disposition on the record. Enumerate every charge a
bundled ledger item covered so an unmade re-judgement is not invisible.
