# KB-03 — Malformed CSS resource declaration: `url(null)`, unterminated `url(`, elided placeholder

- **Class:** A. Theme defect, file-provable
- **Detection cost:** pure grep
- **Provability:** FILE-PROVABLE
- **Evidence source:** R/KNOWLEDGE-SEED-INVENTORY.md (compiled 2026-11-17 from the GOSIGN2 review reports and coordinator adjudications named there).

## Mechanism

A CSS declaration whose `url()` is empty (`url(null)`), unterminated (missing
`)` invalidates the whole declaration), or an elided editorial placeholder
(`url(https://…)`) never loads anything: the browser requests `/null` (404 on
every combo) or drops the declaration, so a header/background silently never
paints, on any Wikidot, independent of Sigma-10.

## Static detection

In the candidate (and in any deployed fragment it delivers, e.g. a `/2` code
block), grep for `url(null)`, `url()`, `url(https://…)`, and `url(` occurrences
whose line lacks a closing `)` before the `;`. Count `url(` vs `)` balance per
declaration block.

## Confirmed instances

aces-and-eights `background: url(null)` in `#header` (canonical line 34; 404
every combo, both pages): REPORT-GOSIGN2-RENDER-S2-A. flopstyle-dark deployed
`/2` fragment: ten unterminated `url(` dropping the header logo and all custom
warning-header illustrations: REPORT-GOSIGN2-LOCALIZE-A row 12 / FIX3-FD.
al-slop: one unterminated `url(` dropping the blockquote background:
REPORT-GOSIGN2-LOCALIZE-A row 2.

## False positives and disposition

None known for `url(null)` / unbalanced `url(` in live code; occurrences inside
`@@…@@` examples or comments are not live. marchen's elided `url(https://…)` is
recorded as a deliberate placeholder under KB-02's ORIGINAL-DEFECT set, not a
port defect.

## Fix

Restore the intended URL (from the original at reference revision) or remove the
dead declaration, per the original's own form.
