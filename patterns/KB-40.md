# KB-40 — Site-theme sigma.min.css runtime-hotlink chain

- **Class:** D. Environment-layer
- **Detection cost:** pure grep
- **Provability:** FILE-PROVABLE
- **Status:** adopted
- **Basis:** measured-render, static-diff
- **Dedupe key:** runtime hotlink / site-theme sigma.min.css chain hosts in render summaries / host-set subtraction on summary text
- **Support:** 2 (measured-render, static-diff)
- **Evidence source:** R/KNOWLEDGE-SEED-INVENTORY.md (compiled 2026-11-17 from the GOSIGN2 review reports and coordinator adjudications named there).

## Mechanism

The check wiki's SITE theme is the Sigma-10 environment candidate, whose
`sigma.min.css` @imports from `rokurolize.github.io` (the Rokurolize/sigma
fork's Pages stylesheet), `rsms.me`, and `scp-wiki.wdfiles.com`. Every page on
the wiki, including the baseline, loads them, so render_check's
`runtime-hotlink` line listing exactly these hosts is the site theme's chain,
not candidate code. The shared sample page additionally loads its font host
`indestructibletype-fonthosting.github.io` on sample pages only.

## Static detection

Disposition by host set: subtract {rokurolize.github.io, rsms.me,
scp-wiki.wdfiles.com} from any page's runtime-hotlink line, and
{indestructibletype-fonthosting.github.io} on samples. Only the remainder is
candidate-own (KB-22). This subtraction is doable from the summary text alone,
no render needed.

## Confirmed instances

AGENTS.md sections 1 and 3; every render report's separation notes (S2-A X7);
RENDER-ROWS-2 and RENDER-ROWS-G disposition headers.

## False positives and disposition

not this pattern; this entry covers runtime lines, not source lines.
