# KB-26 — WebKit sidebar-not-opening with the control present (marchen class)

- **Class:** B. Theme defect, triage only
- **Detection cost:** needs live probe
- **Provability:** TRIAGE
- **Status:** adopted
- **Basis:** measured-render
- **Dedupe key:** sidebar toggle / control present in WebKit but the open-state cascade fails / open-state rule surface, WebKit screenshot confirms
- **Support:** 1 (measured-render)
- **Evidence source:** R/KNOWLEDGE-SEED-INVENTORY.md (compiled 2026-11-17 from the GOSIGN2 review reports and coordinator adjudications named there).

## Mechanism

Sibling of KB-25: the hamburger renders in WebKit, but activating it does not
bring the drawer on-screen (the open-state rule, transition, or
z-index/transform chain fails only in WebKit), while Chromium opens normally.
Desktop WebKit (1366) is the confirmed surface; mobile opens in both engines.

## Static detection

Same triage surface as KB-25 (own `.open-menu` / `#side-bar` rules, `-webkit-`
mentions), plus rules keyed on the open state (`.open-menu` active classes,
`#side-bar` transform/left transitions). Presence of the control in source
proves nothing; the failure is in the open-state cascade.

## Confirmed instances

marchen, page and sample: WebKit 1366 hamburger present, sidebar does not open;
Chromium sidebar screenshot shows it open at left; machine `sidebar-not-opening`
[webkit 1366x768] corroborates: REPORT-GOSIGN2-RENDER-S2-RERUN16.

## False positives and disposition

magicity's machine `sidebar-not-opening` [webkit 768x1024] was NOT reproduced in
its WebKit sidebar screenshot (drawer open): RERUN16 records it verbatim in T2
and does not re-report it as a visual finding. A machine line without the
screenshot is not this pattern.

## Fix

Per-theme correction of the open-state rules for WebKit.

## Sweep amendment (2026-11-17, SWEEP-B)

Risk set: 79 themes (the KB-25 tier A/B population further required to carry open-state rules). The confirmed instance marchen is in the set, and magicity is in the set while its render evidence already on file clears its visual form, as the pattern records.
