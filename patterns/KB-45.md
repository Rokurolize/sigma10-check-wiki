# KB-45 — Measurement non-completion (exit 2 / no summary.md; networkidle baseline failure)

- **Class:** E. Capture and measurement artefact, not a result
- **Detection cost:** pure grep
- **Provability:** FILE-PROVABLE
- **Evidence source:** R/KNOWLEDGE-SEED-INVENTORY.md (compiled 2026-11-17 from the GOSIGN2 review reports and coordinator adjudications named there).

## Mechanism

render_check navigates with `wait_until="networkidle"` (90 s, hardcoded) and
measures the target against a baseline page
(`https://scp-jp.wikidot.com/custom-theme-policy`) that is ad-heavy and slow.
Under box load the baseline or the target times out: the run exits 2, or exits 1
with a crash traceback and NO summary.md. No measurement exists; any verdict
recorded from such a run is a verdict without evidence.

## Static detection

Check for the presence of `summary.md` per target before reading any verdict:
exit 2, or exit 1 without summary.md, means NOT MEASURED. Distinguish a crash
traceback (exit 1, no summary) from a real exit 1 (summary present). Sequential
retries beat parallel retries; lane-local variants (load instead of networkidle,
cached baseline) are lane-local accommodations, not precedent.

## Confirmed instances

The 17 rerun themes themselves (both pages exit 2 / no summary in the C..F
original runs, FINDINGS recorded with no measurement): RENDER-ROWS-2 gap
analysis, closed by RERUN16 (34/34 summaries after retries). flopstyle-dark T2
did not complete in RENDER-B (webkit target timeout / baseline crash, no
summary).

## False positives and disposition

T2 non-completion is a network/server disposition, never BLOCKED-ENV and never a
theme finding (AGENTS.md section 3).

## Fix

Re-run the target (serially, with a shell timeout) until a summary exists or the
failure is proven deterministic.
