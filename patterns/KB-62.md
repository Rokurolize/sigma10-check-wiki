# KB-62 — fa-info rule absence in OWN credit candidates (A4 sub-pattern)

- **Class:** B. Theme defect, triage only
- **Detection cost:** cross-file diff
- **Provability:** TRIAGE
- **Evidence source:** sigma10-review-20261117/LEDGER.md axis A4 (credit/info module styling survey, all 287 candidates); findings/A3.md (3law-pride root cause).

## Mechanism

Candidates that style the credit module in their own text (A4 class
OWN) usually also need an explicit `.fa-info` rule: the credit button's
info icon is positioned and sized by theme CSS, and where no rule
reaches it the icon renders displaced or at a default size (the
displaced-"i" symptom confirmed on 3law-pride). The full supplement
shape is visible in theme:cosmonaut-jp.txt lines 1026-1110, including
explicit `.fa-info` sizing at lines 1042-1060. A candidate can carry
credit selectors yet silently lack this one rule, because icon
positioning is widely assumed to arrive from the base or the component
rather than shown in the candidate's own text.

## Static detection

For each candidate in A4 class OWN (credit selectors in its own text),
grep both CSS channels (`[[module CSS]]` and `[[code type="css"]]`) for
`fa-info`. Absence nominates the theme. Before charging, subtract the
resolved base: an INHERIT or INHERIT-EXT candidate may receive the
rule from its base, and for the 80 of 287 candidates whose operative
CSS lives partly outside the repo text the cell is
UNDECIDABLE-FROM-REPO (see SWEEP-PROTOCOL.md).

## Confirmed instances

Exposure set (A4): 107 of the 160 OWN candidates have no fa-info rule
in their own text; only 37 of 287 candidates carry the full
cosmonaut-style set. No theme is confirmed as a defect by this absence
alone; the motivating confirmed case is 3law-pride, whose displaced
info icon is one symptom of its entirely missing credit supplement
(KB-11, root cause in findings/A3.md).

## False positives and disposition

Absence in own text is a triage signal, not a verdict: the rule may
arrive via the base include, a published base file, or the credit
component's own defaults may be adequate for that theme's layout.
Render confirmation on the candidate's sample (real credit module)
decides. Never disposition a row on this pattern without that check.

## Fix

Add a `.fa-info` rule in the candidate's credit supplement, sized and
positioned as in the cosmonaut exemplar, only where a re-render still
shows displacement (the A3 fix shape).
