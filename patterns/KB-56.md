- **Class:** F. Named exception / standing disposition

- **Dedupe key:** documentation example / escaped :oxygennine:peroxide: examples in peroxide only / escaped-context grep, 20 occurrences

## Mechanism

Twenty occurrences of `:oxygennine:peroxide:*` includes appear in
peroxide-family candidates, ALL inside escaped documentation examples: nothing
live renders from them. The component family ports with the theme at posting
(ruling 4), so the draft-stage lines are inert by construction.

## Static detection

For every `:oxygennine:peroxide:` hit, verify the `@@…@@` escaping context;
escaped = this exception. A LIVE peroxide include would not be this pattern and
would go through KB-15.
