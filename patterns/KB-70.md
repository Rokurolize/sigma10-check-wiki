# KB-70 — Code-block delivery address not recounted after block edits

- **Class:** A. Theme defect, file-provable
- **Detection cost:** cross-file diff
- **Provability:** FILE-PROVABLE
- **Status:** adopted
- **Basis:** static-diff, live-probe
- **Dedupe key:** local--code address / a candidate's local--code/<own>/N reference whose ordinal no longer names the CSS block after [[code]] blocks were added, removed or reordered / count code blocks to the CSS exhibit and probe the addressed block's served bytes
- **Support:** 2 (static-diff, live-probe)
- **Evidence source:** R/review-scout/BATCH-MFRAME3.md proposal 1, BATCH-MPURE4.md proposal 1, BATCH-RFIX15.md proposal 1 (gp-refresh), and the FIX-CODEADDR audit record.

## Mechanism

A theme's own compiled CSS is delivered through
`local--code/<own-fullname>/N`, where N is the ordinal of the page's
`[[code]]` block. When a port inserts, deletes or reorders `[[code]]`
exhibits ahead of the CSS block without recounting, N addresses the wrong
block. The wrong block may be an exhibit or a preliminary fragment; the
delivery silently loads the wrong bytes. Restorations are the classic
trigger: a substantively correct fix that inserted a code exhibit
silently renumbered delivery.

## Static detection

For each candidate, count `[[code]]` blocks in document order and
identify which one holds the delivered CSS. For every self-addressed
`local--code/<own>/N` reference, compare N against the CSS block's
ordinal. Flag (a) N naming a non-CSS or preliminary exhibit, (b) any
self-address on a page with zero `[[code]]` blocks or live-module-only
delivery, and (c) a frame target naming a different page name than the
candidate's own. The deciding probe fetches each `/N` and compares its
served byte size against the block it should name (served-size census),
not against block position alone.

## Confirmed instances

enlightened-eyes (address /1 while the CSS exhibit is the sixth block,
probe-verified, BATCH-MPURE4), gp-refresh (restoration renumbered
delivery, the fixing lane's control was blind to it, BATCH-RFIX15), and
the FIX4-IWA 31-theme recipient list re-swept by BATCH-MFRAME3, which
found the defect in 4 of 8 sampled themes. Contrast cases with a correct
count: eventyr, extra-black-highlighter-theme, ethic-committee,
flowergarden.

## False positives and disposition

A self-address naming a block that serves the correct bytes is not a hit
even if the ordinal looks unusual. Re-emitted byte-identical lines are
not hits (cf. KB-65's identical-line suppression). A plain un-suffixed
slug on the JP host is the same census extended (steam-guide).

## Fix

Recount every self-addressed `local--code` reference from the candidate's
own bytes after any code-block insertion or deletion, and re-run the
served-size census before closing the lane. Fetch the addressed block
once to confirm it serves the CSS. Do not trust block position from a
pre-edit snapshot.
