# KB-28 — Unreadable color pair (theme palette applied to the wrong surface)

- **Class:** B. Theme defect, triage only
- **Detection cost:** needs live probe
- **Provability:** TRIAGE
- **Status:** adopted
- **Basis:** measured-render
- **Dedupe key:** color pair / foreground-background pair composed at near-1.0 contrast on a reader surface / pair computation including cross-rule and variable-pair composition, screenshot confirms
- **Support:** 1 (measured-render)
- **Evidence source:** R/KNOWLEDGE-SEED-INVENTORY.md (compiled 2026-11-17 from the GOSIGN2 review reports and coordinator adjudications named there).

## Mechanism

The theme's palette variables are resolved against a surface the port changed:
sample panels, content panels, or body text inherit a near-white foreground
meant for dark surfaces onto the sample's light background (or near-black onto
dark navy panels), because the port's variable mapping or the sample's panel
classes bind the wrong variable pair. Contrast collapses to about 1.0-1.1 while
every individual color value looks intentional in the file.

## Static detection

Triage: extract the candidate's palette variables and the foreground/background
pairs for body text and panel classes; compute contrast ratios for the pairs the
sample construction actually composes (theme panel classes on the shared
sample's light sections). Near-1.0 ratios on body-text pairs nominate the theme;
variable-driven palettes with variant switching (magicity) cannot be settled
statically.

## Confirmed instances

old-money-theme sample: notice and column panel text #F7F8F9 on #F4F4F4,
unreadable in both engines (RERUN16). kitchen page and sample: body text
rgb(254,254,254) on pale pink --BG(244,240,240), machine contrast min 1.06,
canonical source has no white body-text rule, so not an intended aesthetic
(RERUN16). magicity sample: table-cell, blockquote and tab-panel text near-black
on dark navy panels (RERUN16). sodium: rating clear-vote near-white on white
effectively invisible (RENDER-ROWS-G). sound sample sections 15/16: near-white
on light (RENDER-ROWS-G). blankstyle: credit contrast 1.07 near-white unreadable
(RENDER-ROWS-1).

## False positives and disposition

Machine `contrast` warns alone are not this pattern (KB-39): cosmonaut's 3.2 is
readable, normal's band warn is a false positive (dark on light blue),
halloween's contrast 1 is redaction by design (KB-37). The finding needs the
screenshot or the computed pair.

## Fix

Correct the variable binding for the affected surface in the candidate
(foreground or background variable), per surface, not a global palette change.
