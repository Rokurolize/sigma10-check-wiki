# KB-37 — Deliberate specimen shapes on display-check samples

- **Class:** C. Cross-cutting, not a defect
- **Detection cost:** cross-file diff
- **Provability:** FILE-PROVABLE
- **Evidence source:** R/KNOWLEDGE-SEED-INVENTORY.md (compiled 2026-11-17 from the GOSIGN2 review reports and coordinator adjudications named there).

## Mechanism

The shared sample body contains deliberate stress specimens: `hl-code` long
unbroken code lines, `bblock`/`dblock` contrast-1 redaction blocks,
`wiki-content-table` wide tables, intentional `em` overflow. Their overflow and
contrast machine lines are the specimen working as designed, on every theme
identically.

## Static detection

Disposition by element: a `content-overflow` or contrast line whose element is
one of the sample's named specimens (readable in the shared sample source) is
by-design. The sample source is one file; learn its specimen inventory once.

## Confirmed instances

AGENTS.md section 3 T2; RENDER-S2-A X3/X5/X6 codes; RERUN16
(shark-punching-centre-bhl hl-code overflow is the deliberate specimen; normal
sample hl-code likewise).

## False positives and disposition

The same shapes in the theme's own usage/examples (not the shared sample) are
judged on their own merits; redaction contrast in a theme's own design
(halloween) is likewise by-design only where the design intent is evidenced.

## Fix

None.
