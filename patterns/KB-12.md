# KB-12 — JP credit-module supplement present but ineffective (night-rush class)

- **Class:** A. Theme defect, file-provable
- **Detection cost:** cross-file diff
- **Provability:** FILE-PROVABLE
- **Status:** adopted
- **Basis:** static-diff, lane-report
- **Dedupe key:** credit module CSS / supplement present but a null-valued companion property in the JP anchor defeats it / correction-block vs anchor property diff
- **Support:** 2 (static-diff, lane-report)
- **Evidence source:** R/KNOWLEDGE-SEED-INVENTORY.md (compiled 2026-11-17 from the GOSIGN2 review reports and coordinator adjudications named there).

## Mechanism

A candidate appends a credit-correction block that redeclares only some
properties of a credit-module rule. CSS cascade keeps the undeclared properties
from the JP anchor (`credit:style`): night-rush-jp's block redeclares
`border-left-color` and `border-left-width` but never `border-left-style`, and
the anchor's `border-left-style: none` wins, so the correction paints nothing at
all. The supplement exists on paper and does nothing in the browser.

## Static detection

For each appended credit-correction rule in the candidate, list the properties
it redeclares and compare against the anchor rule in the JP credit style source:
any visual property whose effect depends on a companion property (border style
for border color/width; `content` display prerequisites; background position
without image) that the block omits and the anchor sets to a null value is the
defect.

## Confirmed instances

night-rush-theme (worked example, AGENTS.md section 9 info-credit audit
residue). Same audit class SUPPLEMENT-PRESENT-BUT-INEFFECTIVE: dear-dictator,
hansarp.

## False positives and disposition

A block that redeclares a self-sufficient property (color alone, font-size
alone) is effective; the defect needs the anchor's null-valued companion
property as evidence.

## Fix

Add the missing companion declaration(s) to the correction block.
