# KB-17 — Font and asset host violations (localize pattern 5)

- **Class:** A. Theme defect, file-provable
- **Detection cost:** pure grep
- **Provability:** FILE-PROVABLE
- **Evidence source:** R/KNOWLEDGE-SEED-INVENTORY.md (compiled 2026-11-17 from the GOSIGN2 review reports and coordinator adjudications named there).

## Mechanism

JP delivery rules restrict live font/asset hosts to the exception list (Google
Fonts, JP-owned storage, sanctioned JP artifacts). A candidate loading fonts
from `fonts.bunny.net`, from `rsms.me` (Inter's own host, not the JP exception
form), or code from the EN BHL delivery host `nu-scptheme.github.io` renders at
the mercy of a non-JP host and, for bunny, contradicts the JP porting rule that
AutoLocalize's Google-to-bunny move is not followed.

## Static detection

Extract all hosts from live `@import`, `url()`, and `[[image]]` references in
the candidate; diff against the exception list in the staff skill / AGENTS.md
section 5. Flag `fonts.bunny.net`, `rsms.me`, `nu-scptheme.github.io` on sight.

## Confirmed instances

al-slop: bunny.net Boogaloo/Margarine live (LOCALIZE-A row 2). basalt: bunny.net
Sofia Sans live (LOCALIZE-A row 3). foxtrot: `rsms.me/inter/inter.css` at L632,
replaced with the Google Fonts Inter variable URL by FIX3-B. inkblot: where the
original's AutoLocalize moved Google to bunny, the port reverts to the pre-move
Google Fonts URLs (AGENTS.md section 5).

## False positives and disposition

`rsms.me` appearing inside the SITE theme's sigma chain at render is
environment-layer (KB-40), not this pattern; this pattern is the candidate's own
source lines. `old-bhl` (nu-scptheme) is class (ii): leave untouched in fix
lanes, rewrite target is `scp-jp.github.io/Black-Highlighter` at posting.

## Fix

Substitute the exception-list delivery (Google Fonts for Inter/bunny families)
in the candidate where the class is (i); otherwise record for posting.
