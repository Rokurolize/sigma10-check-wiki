# KB-22 — Candidate-own runtime hotlink hosts (judgment-required signal)

- **Class:** A. Theme defect, file-provable
- **Detection cost:** needs live probe
- **Provability:** TRIAGE
- **Evidence source:** R/KNOWLEDGE-SEED-INVENTORY.md (compiled 2026-11-17 from the GOSIGN2 review reports and coordinator adjudications named there).

## Mechanism

At render, a candidate loads runtime resources from hosts that are neither the
site theme's chain (KB-40) nor the shared sample's hosts. Each such host is a
live dependency the port has not accounted for: some are posting-time re-host
items, some are the theme's own sanctioned delivery, some are genuine foreign
dependencies. The render checker records them verbatim because no static list
can adjudicate them.

## Static detection

Enumerate every external host in the candidate's live code (imports, url(),
images, includes) and subtract: the environment hosts (KB-40, KB-41), the
exception-list hosts (KB-17 fix forms), and JP-owned storage. The remainder is
the candidate-own host set to adjudicate per theme, before any render: for each,
decide re-host at posting / sanctioned delivery / foreign dependency, with
evidence.

## Confirmed instances

ordopharm and broken-world family: `cdn.jsdelivr.net` charged as candidate-own
(RENDER-S2-RERUN16). betwixt: `hormress.github.io`, `nu-scptheme.github.io`,
ah-sandbox hosts (RERUN16). kitchen: `scpsandboxcn.wdfiles.com` burger-sequence
images, checker error 126 at source level (RERUN16-PARTIAL static prediction,
confirmed at render). normal: `hormress.github.io/Parallel/…` preset @imports,
the candela/parallel precedent applies (KB-55 family). share-future-community:
`hoah.backroomswiki.cn` (RENDER-ROWS-G).

## False positives and disposition

Hosts that are the theme's own original-side storage slated for posting re-host
are class (ii), not defects; the signal is the enumeration, the charge requires
the per-host adjudication.

## Fix

Per host: repoint to the JP port's delivery, re-host at posting, or record as a
named exception with evidence.
