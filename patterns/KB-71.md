# KB-71 — Delivered CSS block structurally voids its own rules

- **Class:** A. Theme defect, file-provable
- **Detection cost:** pure grep
- **Provability:** FILE-PROVABLE
- **Status:** adopted
- **Basis:** static-diff
- **Dedupe key:** delivered block structure / an unterminated comment, an unbalanced brace depth, or a mid-rule truncation that silently removes rules from a delivered CSS block / first-*/before-first-rule check plus brace-depth profile
- **Support:** 3 (static-diff, lane-report)
- **Evidence source:** R/review-scout/BATCH-MPURE1.md proposal P-2, BATCH-RFIX14.md proposal 1 (starbasalt), BATCH-RFIX21.md proposal 4 (writing-anomalies), BATCH-U9.md proposal 4 (wikifot).

## Mechanism

A porter banner comment added at the head of a delivered stylesheet can
be left unterminated, commenting out the first many lines; brace counts
stay plausible and the file still appears to have all its rules. A block
can also end at a nonzero brace depth (an original-side damage the port
repaired silently), or an original module can end mid-rule with the
candidate supplying exactly the closing braces. In all three forms the
static shape is visible but no standing check reads it: the rules are
silent, not absent from the text.

## Static detection

For each delivered CSS block (both channels, tolerant parsing per
SWEEP-PROTOCOL.md): require the first `*/` to precede the first rule or
`@import`, and every `/*` to terminate within the block. Compute a
brace-depth profile: the longest continuous depth >= 1 span and the count
of lines ending at depth 0. A block ending above depth 0, or a depth that
never returns to 0 over a long span, is the hit. A whitespace-normalized
token-delta count localizes a single lost or gained brace token.

## Confirmed instances

starbasalt (unterminated porter banner commenting out the first 102
lines, items 86/87), anniversary (84/84 raw braces but depth never
returns to 0 for 405 lines), writing-anomalies (original ends at depth
3, damage repaired silently), wikifot (original module ends mid-rule,
candidate adds the closing braces).

## False positives and disposition

A CSS `url(none)`/unterminated `url(` shape is KB-03, not this pattern
(KB-03 is a malformed resource declaration, not block structure). An
unterminated @import or a spaced `theme=` parameter that renders benign
is a recorded form deviation, not a hit. Balance across the whole file
does not clear a block whose own depth never returns to 0.

## Fix

Terminate the banner comment, restore the missing brace, or record the
truncation repair in the explanation. Use the depth profile as the T1-side
acceptance test, not a raw brace count.
