This is the Alcur Hospital theme, a Basalt-based theme created by [[*user ApothecaryCat21]] with assistance from [[*user dxxander]]. This theme was created for use with the GoI [[[the alcur hospital hub|Alcur Hospital.]]] Basalt **must** be included above this theme in order for it to work properly.
