/*
    태평양사령부 1943 / PACOM 1943 — Ported for SCP-JP (theme:pacom1943 rev 43 on scpko).
    原語版は theme:pacom（同じ作者）を基盤に 1943 年版の配色と画像を差し替えた亜種です。基盤 CSS は
    theme:pacom-jp を hidden include で読み込みます（このファイルには含まれていません）。フォントは原語版の
    UnJamoBatang を Google の Gothic A1 で代替しています（theme:pacom-jp と同一の差し替え）。
*/

@charset "utf-8";

/*
    태평양사령부 CSS 테마

\*-----------------------*/
