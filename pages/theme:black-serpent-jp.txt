これは[[*user Jerden]]によるBlack Highlighter基盤のテーマです。[[[theme:wanderers|放浪者の図書館テーマ]]]の代替として、とくに[[[serpent-s-hand-hub|蛇の手]]]要注意団体と『[[[https://scp-wiki.wikidot.com/now-the-serpent|Now, the Serpent]]]』シリーズのために作成されました。ヘッダー画像の原案は[[*user Zyn]]によるものです。

------

このテーマを使用するには、Black Highlighterテーマも併せて読み込む必要があります。Black Highlighterテーマの詳細は[https://scp-jp.wikidot.com/theme:black-highlighter-theme こちら]をご覧ください。

/*
    Black Serpent Theme
    [2025 Wikidot Theme]
    by Jerden
    Based on Black Highlighter
    Ported for SCP-JP (theme:black-serpent rev 12)
*/

@import url("https://scp-jp.github.io/Black-Highlighter/css/min/normalize.min.css");
@import url("https://scp-jp.github.io/Black-Highlighter/css/min/black-highlighter.min.css");

@import url("https://fonts.googleapis.com/css2?family=Londrina+Outline&display=swap");
@import url("https://fonts.googleapis.com/css2?family=Farro:wght@300;400;500;700&display=swap");

/* 日本語フォント (JP localization) */
@import url('https://fonts.googleapis.com/css2?family=Noto+Sans+JP:wght@400;700&display=swap');

:root {
    /* S-CSS-P Integration */
    --theme-base: "nuscp";
    --theme-id: "black-serpent";
    --theme-name: "Black Serpent Theme";

    /* ===THEME COLORS=== */
    /* theme color */
    --medium-accent: 0, 100, 55;
    /* dark theme color */
    --dark-accent: 20, 55, 20;
    /* bright theme color, the "default" accent color*/
    --bright-accent: 0, 125, 0;
    /* pale theme color, for visited links */
    --pale-accent: 45, 110, 44;
    /* alternate accent color, for newpage links */
    --alt-accent: 71, 92, 75;

    /* ===THEME HEADER=== */
    --logo-image: url("https://sigma10-jp-test.wdfiles.com/local--files/theme%3Ablack-serpent-jp/Serpents-Hand.svg");
    --header-title: "SERPENT'S HAND";
    --header-h1-font-size: calc(var(--base-font-size) * (2.4));
    --header-subtitle: "The Anomalous is on the Rise";
    --header-h2-font-size: calc(var(--base-font-size)*1);
    --header-font: 'Londrina Outline', "Noto Sans JP", sans-serif;
    --title-font: 'Farro', "Noto Sans JP", sans-serif;
}

/* ===PAGE CONTENT=== */
#main-content {
    --tables-header-bg: var(--medium-accent);
}

:is(blockquote, div.blockquote) {
       border: 1px solid rgb(var(--dark-gray-monochrome));  
       border-left: 5px solid rgb(var(--bright-accent));
       background-color: rgb(var(--pale-gray-monochrome));
}
