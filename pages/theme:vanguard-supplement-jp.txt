+ 使用方法
[[/=]]

これはVanguard Sigma-9テーマの補完コードです。親テーマである[[[theme:scp-human-resources-sigma-jp|Human Resources Sigma-9 Theme]]]はtheme:scp-human-resources-sigma-jpとしてSCP-JPに投稿されており、このテーマはそれを hidden include で読み込みます。

このテーマをページへ読み込むには、ページ内の任意の場所に以下を入れてください:

[[div class="code"]]
@@[[include :scp-jp:theme:scp-human-resources-sigma]]@@
@@[[include :scp-jp:theme:vanguard-supplement]]@@
[[/div]]

サイドバーを隠したい場合は、上記の後に以下を入れてください:

[[div class="code"]]
@@[[include :scp-jp:component:toggle-sidebar]]@@
[[/div]]

各ページのバックリンクは、ページ下部の「+ オプション」をクリックし、続けて「バックリンク」を選ぶと確認できます。

/* ===== Vanguard Supplement（本テーマ） ===== */
/*
    Vanguard Supplement
    [2024 Wikidot Theme]
    By macro_au_micro
    Adapted from the code used to transform the BHL Human Resources theme into a Vanguard theme by Placeholder McD in the SCP-6500 Emissary Path
    Based on SCP Sigma 9 Theme created by Aelanna and Dr Devan
*/

/* HEADER */

#header, div#header {
     background-image: none;
}

    position: absolute;
    width: 100%;
    height: 100%;
    content: "";

    top: 1rem;
    z-index: -1;

    background-image: url('https://scp-jp-storage.wdfiles.com/local--files/file%3A2963469-77-1a78/vanguard%20transparent.png');
    background-position: center top;
    background-repeat: no-repeat;
    background-size: auto 9em;
    filter: brightness(125%);
}

#header h1,
#header h2 {
    margin-left: 0;
    float: none;
    text-align: center;
}

#header h2 {
    margin-top: 2rem;
}

#header h2 span {
    font-size: 0;
    display: none;
}

    color: rgb(207, 223, 245);
    letter-spacing: -.02em;
    line-height: 0;
}

#header h1 a::before {
    content: "ANGUARD";
    font-size: unset;
}

#header h2::before {
    content: "保護 - 正常化 - 告知";
    font-size: 110%;
}

div#container-wrap {
    background-image:
        repeating-linear-gradient(45deg,

        rgba(7, 7, 40, 1) 10.125rem,

        rgba(63, 97, 145, 1) calc(99% - 0.125rem)) !important;

    background-size: 100% 10.125rem, 100% 10.125rem, 100% 11.438rem !important;
    background-repeat: no-repeat;
}

div#content-wrap {
    top: 1.375rem;

}

}
