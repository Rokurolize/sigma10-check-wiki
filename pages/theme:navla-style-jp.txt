+ これは何？
# [[*user Navla]]が作成した汎用テーマです。
# どの連作・カノン・GOIFとも無関係の、純粋に美学上のテーマです。
# 自分がこれまで作ってきたテーマを置き換え、必要なテーマを簡単に拡張しようと作られました。
# 個人的な趣味をふんだんに盛り込んで作られました。
# シグマ9系のテーマです。

++ 使い方
次のコードを編集画面に貼り付けてください。
> @@[[include :scp-jp:theme:navla-style-jp]]@@
使用可能な引数は次の通りです。
* tocbox=1 : ページ左上に目次入りのサイドボックスを表示します。
* help=1 : ナブラコンポーネントに存在するクラスを紹介するヘルプボックスを表示します。
各引数は "|" で区切ってください。

> **例）** 本文に目次サイドボックスとヘルプボックスを追加する:
> @@[[include :scp-jp:theme:navla-style-jp tocbox=1|help=1]]@@

**訳注:** 原語版の引数 `preset`（プリセットカラー）と `flag`（プライドロゴ）は、JP版では未対応です（KO wiki 上の別ページに依存するため）。代わりに、以下の変数再宣言で同等のカスタマイズが可能です。プリセットが必要な場合は、スタッフまでご相談ください。

++ 主な変数
ナブラスタイルは、カスタムが簡単に設計されています。複数の変数の再宣言を通じて、思い通りに調整できます。
特に、手軽に変更できる変数は次の通りです。これ以外にもカスタムを助ける様々な変数があります。より詳しいカスタム方法については、原語版の[[[https://scpko.wikidot.com/navla-style-preset-and-custom|プリセット・カスタム]]]ページ（韓国語）を参照してください。

変数の再宣言は、テーマの宣言より後に以下のコードを書くことで行えます。
[[div class="blockquote"]]
@@[[module CSS]]@@
:root:lang(ja) {
@@    --好みの-変数1: 好みの値;@@
@@    --好みの-変数2: 好みの値;@@
}
@@[[/module]]@@
[[/div]]

基本的な変数は次の通りです。
[[code type="css"]]
:root:lang(ja) {
    --theme-color: 120, 120, 120; /* テーマのハイライト色です。 */
    --theme-color-dark: 60, 60, 60; /* より暗いハイライト色です。 */
    --logo-image: url('https://sigma10-jp-test.wdfiles.com/local--files/theme%3Anavla-style-jp/SCP_Foundation_emblem.svg'); /* ロゴ画像です。#header-extra-div-1 の背景画像になります。 */
    --header-title: "SCP財団"; /* ヘッダーのタイトルテキストです。 */
    --header-subtitle: "確保、収容、保護"; /* ヘッダーのサブタイトルテキストです。 */
}
[[/code]]

++ カスタムについて
原語版で提供されているプリセット（preset=1 など）は KO wiki 上のページに依存するため、JP版には含まれていません。色は上記の変数再宣言で自由に変更できます。
