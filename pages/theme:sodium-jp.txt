これは[[*user Ankv]]による美的なテーマで、特定のSCP・物語・GoIフォーマット・設定には紐づけられず、既存のどのテーマにも基づいていません。デザインには[[*user EstrellaYoshte]]の[[[theme:monotypical|Monotypicalテーマ]]]を参考にしています。

このテーマの内蔵機能：
* 切り替え式サイドバーコンポーネント
* タブページのアニメーション
このテーマを使用するには、使用する記事の先頭に次のコードを追加してください。

+ 例

[[include component:image-block name=https://sigma10-jp-test.wdfiles.com/local--files/theme%3Asodium-jp/logo2.png|caption=画像。|width=200px]]

5個の連字符「@@-----@@」で水平線を作れます。何かの中（引用ブロックなど）に置かれていなければ、左右いっぱいに広がります。ページを複数の節に分けるこの線が水平線です。

見出しは、行頭に1個から6個のプラス記号「+」を置いて作成できます。

普通の__下線__**太字**//斜体//--取り消し--{{等幅}}__**//--{{字}}--//**__

もう一つの普通の __下線__ **太字** //斜体// --取り消し-- {{等幅}} __**//--{{字}}--//**__

| [https://www.example.com/ これはリンク！] | [[[4o4-n0t-f0und|空のリンク！]]] | [[a href="https://scp-jp.wikidot.com/"]]普通の__下線__**太字**//斜体//--取り消し--{{等幅}}__**//--{{リンク}}--//**__[[/a]] | [[a href="https://scp-jp.wikidot.com/"]]もう一つの普通の __下線__ **太字** //斜体// --取り消し-- {{等幅}} __**//--{{リンク}}--//**__[[/a]]

[[code type="css"]]
/* sodium-jp：テーマ独自の CSS（Sodium 基盤は fragment:sodium-jp-base-css を @import で読み込みます） */

/* SCP-JP環境向けの補正: JPのcreditコンポーネント（credit:start-preview）は .creditButton の直接の子 a 要素を出力する。
   このテーマの規則は .creditButton p a に書かれているため、そのままではJP環境で効かない。
   同じ指定を直接の子 a にも当てる（対象は現在のクレジットボタンのマークアップのみ）。 */
#page-content .rate-box-with-credit-button .creditButton > a {
    margin-left: 0;
    padding-top: 0;
    line-height: 25px;
    height: 25px;
    border: none;
    width: 25px;
    color: var(--sodium-text-color);
    transition: all 0.2s ease-in-out;
}

#page-content .rate-box-with-credit-button .creditButton > a:hover {
    background-color: var(--sodium-link-color);
    color: var(--sodium-hover-color);
}

#page-content .rate-box-with-credit-button .creditButton > a::before {
    position: relative;
    top: 1px;
}
