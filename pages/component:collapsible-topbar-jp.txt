**折り畳み式トップバー**

[[>]]
[[module Rate]]
[[/>]]

トップバーをもう一段階折り畳んで隠すコンポーネントです。テーマ制作時、PCやモバイル環境でトップバーの項目が長すぎて扱いにくい場合に使用すると便利です。使用する文書に以下の構文をコピー＆ペーストしてください。

> @@[[include component:collapsible-topbar-jp]]@@

必要であれば、以下の引数を適切に再宣言してください。

* **maxw**
 * この値以上の画面幅を持つPC環境ではトップバーを折り畳みません。
 * 767px ~ 10000px
 * 以下の各引数を機能させるには、maxw引数を手動で入力する必要があります。
* **top-color**
 * トップバーを展開するボタンのテキスト色を変更します。
 * デフォルト: #FFF
* **top-bg**
 * 展開された状態でのトップバーの背景色を変更します。
 * デフォルト: 透明
[[/iftags]]

[[module CSS]]
.mobile-top-bar {
  max-width: 100% !important;
}

#top-bar {
  color: #FFF;
}

@media (max-width: {$maxw}) and (min-width: 768px) {
  #top-bar {
    visibility: hidden;
  }
  #top-bar > div > ul::before {
    content: "メニュー";
    color: {$top-color};
    text-align: right;
    visibility: visible;
    display: block;
  }

  #top-bar:hover {
    width: 100%;
    visibility: visible;
    background-color: {$top-bg};
    border-left: 300px solid {$top-bg};
  }
  #top-bar:hover > div > ul::before {
    visibility: hidden;
    display: none;
  }
}

@media (max-width: 767px) {
  .mobile-top-bar {
    width: 100%;
  }

  #top-bar {
    visibility: hidden;
  }
  #top-bar .open-menu a {
    visibility: visible;
    display: block;
  }
  #top-bar > div > ul::after {
    content: "◀";
    color: {$top-color};
    text-align: right;
    visibility: visible;
    display: block;
  }

  #top-bar:hover {
    visibility: visible;
    width: 100%;
    background-color: {$top-bg};
    border-left: 300px solid {$top-bg};
  }
  #top-bar:hover > div > ul::after {
    visibility: hidden;
    display: none;
  }
}

@media (max-width: 385px) {
  .mobile-top-bar {
    width: 97%;
  }
}
