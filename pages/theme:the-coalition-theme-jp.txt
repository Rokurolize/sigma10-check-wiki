+* 使い方

これはBlack Highlighterベースのテーマです。そのため、このテーマを使うにはBlack Highlighterテーマも読み込む必要があります。詳しくは[[[theme:black-highlighter-theme|こちら]]]を参照してください。

**このテーマを読み込むには、ページに以下を追加するだけです。**

> @@[[include :scp-jp:theme:black-highlighter-theme]]@@
> @@[[include :scp-jp:theme:the-coalition-theme-jp]]@@

@@ @@

水平線は、5つのハイフン「@@-----@@」を使うと作れます。何かの内側（ブロック引用など）に置かれていなければ、ページ全体を横切ります。この文書のセクションを区切っている線が水平線です。

見出しは、行頭に1個から6個のプラス記号「+」を置くと作れます。

+* コード
[[collapsible show="▼ コードを表示" hide="▲ コードを隠す"]]
[[code type="css"]]
/*
    連合テーマ
    [2020年 Wikidotテーマ]
    GreyveがCalibri BoldとCroquemboucheの協力を得て作成。
    WoedenazとCroquembouche作成のBlack Highlighter Themeを基礎とする。
    CC BY SA 3.0.
*/

/* フォント */
@import url('https://fonts.googleapis.com/css2?family=Roboto:wght@400;500&family=PT+Mono&family=Noto+Sans+JP:wght@400;500;700&display=swap');

/* ROOT - ヘッダーと全体の配色 */
:root {

    /* イントロ */
    --theme-base: "nuscp";
        --theme-id: "the-coalition-theme";
        --theme-name: "The Coalition Theme";

    /* ヘッダー */
    --logo-image: url("https://sigma10-jp-test.wdfiles.com/local--files/theme%3Athe-coalition-theme-jp/GOClogo.png");
    --header-title: "世界オカルト連合";
    --header-subtitle: "事務次長室より";
    --header-gradient-color-bottom: 44, 74, 120;
    --header-gradient-color-middle: 44, 74, 120;
    --header-gradient-color-top: 44, 74, 120;
    --gradient-header: linear-gradient(to top,
            rgb(var(--header-gradient-color-bottom)) 100%,
            rgb(var(--header-gradient-color-middle)) 100%,
            rgb(var(--header-gradient-color-top)) 100%);
    --diagonal-stripes: unset;

    --body-font: 'Roboto', 'Noto Sans JP', 'Hiragino Sans', 'Yu Gothic', 'Meiryo', sans-serif;
    --header-font: 'Roboto', 'Noto Sans JP', 'Hiragino Sans', 'Yu Gothic', 'Meiryo', sans-serif;
    --title-font: 'Roboto', 'Noto Sans JP', 'Hiragino Sans', 'Yu Gothic', 'Meiryo', sans-serif;
    --mono-font: "PT Mono", "Noto Sans JP", "Andale Mono", "Courier New", Courier, monospace;

    /* Colors */
    --white-monochrome: 252, 252, 252;
    /* White */
    --pale-gray-monochrome: 244, 244, 244;
    /* Light Grey (Quoteblocks) */
    --light-gray-monochrome: 170, 170, 170;
    /* Accent Light Gray (Login Status) */
    --gray-monochrome: 66, 66, 72;
    /* Gray */

    --pale-accent: 167, 188, 201;
    /* Pale Blue*/
    --bright-accent: 56, 117, 161;
    /* Steel Blue*/
    --medium-accent: 44, 74, 120;
    /* Deep Blue */
    --dark-accent: 32, 40, 78;
    /* Navy */
    --newpage-color: 187, 225, 250;
    /* Pale Turquoise */

    /* Primary Header Colors */
    --swatch-headerh1-color: var(--white-monochrome);
    --swatch-headerh2-color: var(--white-monochrome);
    --swatch-topmenu-border-color: var(--dark-accent);
    --swatch-topmenu-bg-color: var(--dark-accent);

    --rating-module-button-color: var(--black-monochrome);
    --rating-module-text-color: var(--black-monochrome);

    /* Link Colors */
    --link-color: 27, 65, 94;
    --visited-link-color: 133, 193, 233;
    --hover-link-color: 133, 193, 233;
}

/* モバイル版トップバーの開閉ボタン */
#top-bar>div.mobile-top-bar>div.open-menu>p>a {
    color: rgb(var(--gray-monochrome)) !important;
}

/* ヘッダーサイズの調整 */

/* モバイル時の画像リサイズを打ち消す */
@media only screen and (max-width: 768px) {
    #header {
        background-size: 0.625rem 2.500rem;
        background-repeat: no-repeat;
        background-position: left 0.75rem top 1.1875rem;
        background-clip: border-box;
        background-size: auto 5.375rem;
    }
}
