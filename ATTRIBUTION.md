# Repository attribution index

This file indexes the Title / Author / Source / License attribution of every review package in this repository. It is the repository-level record that the campaign owed before public upload: each package README's **License and attribution** section is the detailed, per-work record, and the census line below states the package population.

Licensed material: every third-party work indexed here is attributed as **Creative Commons Attribution-ShareAlike 3.0 (CC BY-SA 3.0)**, https://creativecommons.org/licenses/by-sa/3.0/. The port changes are adaptations of those works and are noted as such in each package README.

Campaign-original material — the review explanations, classifications, generated diffs and stamps, and the tooling (`review/build_review.py`, `review/classify_hunks.py`, `build_start.py`, `formal/audit_repo.py`, the README prose and this index) — is released under the same **CC BY-SA 3.0** terms as the material it documents. No prior separate license instrument for campaign-original material was found in this repository; this line is the stated position for the public release.
