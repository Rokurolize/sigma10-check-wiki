+* Usage

This is a Black Highlighter based theme by [[*user Heck_Tech]] and [[*user dddaker]] for the Febris Pharmaceuticals GOI. Here you will find a basic aesthetic theme and some custom //[[divs]]// you can use to enhance your articles!

You will need to import the Black Highlighter theme as well in order to use this theme. [[[theme:black-highlighter-theme|To learn more go here]]].
