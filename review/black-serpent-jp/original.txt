This is a Black Highlighter-based theme by [[*user Jerden]]. This was created as an alternative for the [[[theme:wanderers| Classic Wanderer's Library theme]]], specifically for the [[[serpent-s-hand-hub|Serpent's Hand]]] Group of Interest and the [[[Now, the Serpent]]] series. The header image was originally created by [[*user Zyn]].

[[image https://scp-wiki.wdfiles.com/local--files/theme%3Ablack-highlighter-theme/black-highlighter-logo.svg]]

------

You need to import the Black Highlighter theme as well in order to use this theme. To learn more about the Black Highlighter theme, go [https://scp-wiki.wikidot.com/theme:black-highlighter-theme here].

**To import this theme, add this to your page:**
[[div class="code"]]
@@[[include :scp-wiki:theme:black-highlighter-theme]]@@
@@[[include :scp-wiki:theme:black-serpent]]@@
[[/div]]

[[collapsible show="+ Show theme code" hide="- Hide theme code"]]
[[code type="css"]]
@import url("https://api.fonts.coollabs.io/css2?family=Londrina+Outline&display=swap");
@import url("https://api.fonts.coollabs.io/css2?family=Farro&display=swap");

:root {
    /* S-CSS-P Integration */
    --theme-base: "nuscp";
    --theme-id: "black-serpent";
    --theme-name: "Black Serpent Theme";

    /* ===THEME COLORS=== */
    /* theme color */
    --medium-accent: 0, 100, 55;
    /* dark theme color */
    --dark-accent: 20, 55, 20;
    /* bright theme color, the "default" accent color*/
    --bright-accent: 0, 125, 0;
    /* pale theme color, for visited links */
    --pale-accent: 45, 110, 44;
    /* alternate accent color, for newpage links */
    --alt-accent: 71, 92, 75;

    /* ===THEME HEADER=== */
    --logo-image: url("https://scp-wiki.wikidot.com/local--files/theme:black-serpent/Serpents-Hand.svg");
    --header-title: "SERPENT'S HAND";
    --header-h1-font-size: calc(var(--base-font-size) * (2.4));
    --header-subtitle: "The Anomalous is on the Rise";
    --header-h2-font-size: calc(var(--base-font-size)*1);
    --header-font: 'Londrina Outline';
    --title-font: 'Farro';
}

/* ===PAGE CONTENT=== */
#main-content {
    --tables-header-bg: var(--medium-accent);
}

:is(blockquote, div.blockquote) {
       border: 1px solid rgb(var(--dark-gray-monochrome));  
       border-left: 5px solid rgb(var(--bright-accent));
       background-color: rgb(var(--pale-gray-monochrome));
}
