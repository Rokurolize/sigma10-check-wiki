+ 预设

推荐的引用顺序是：先引用过氧化物本体（可以调整参数），再引用布局方案，最后引用配色预设。配色预设会覆盖前面的设置。

+ 自定义

可以通过引用参数对过氧化物进行简单的自定义。请复制下面的引用模板。

**在使用模板时不要删除参数——如果你只希望改动其中一两个参数，那就把剩下的完整保留。**

[[div class="code"]]
@@[[include :scp-wiki-cn:theme:peroxide@@
|##ff8f8f|custom##=*
[[span style="user-select: none; opacity: 0.4"]]↑ 启用自定义参数。[[/span]]
|##ff8f8f|title##='SCP基金会'
[[span style="user-select: none; opacity: 0.4"]]↑ 版头标题。左右使用半角引号括住。[[/span]]
|##ff8f8f|slogan##='控制 / 收容 / 保护'
[[span style="user-select: none; opacity: 0.4"]]↑ 版头副标题。左右使用半角引号括住。[[/span]]
|##ff8f8f|logo##={{url('https://oxygennine.github.io/Peroxide/Images/scp-logo-line-black.svg')}}
[[span style="user-select: none; opacity: 0.4"]]↑ 版头LOGO。以CSS url()格式引入。[[/span]]
|##ff8f8f|colorLight=###3b69e4
[[span style="user-select: none; opacity: 0.4"]]↑ 亮一些的主题色。[[/span]]
|##ff8f8f|colorNormal=###3d5cab
[[span style="user-select: none; opacity: 0.4"]]↑ 主题色。[[/span]]
|##ff8f8f|colorDark=###354f96
[[span style="user-select: none; opacity: 0.4"]]↑ 暗一些的主题色。[[/span]]
|##ff8f8f|logoInvert=##
[[span style="user-select: none; opacity: 0.4"]]↑ 是否将LOGO黑白反转；填“*”启用。[[/span]]
]]
[[/div]]

++ 布局

[[module CSS]]

@media (max-width: 768px) {
.mobileno {display: none;}
}

[[/module]]

{{#page-content}}被设置成类似流明冲击的纵轨道，可以使用下列class的div制作整个页面宽度范围的布局：

[[div class="fullwidth-start end-extrude-start mobileno"]]
= **{{fullwidth}}**
= 全宽
[[/div]]
[[div class="extrude-start end-content-start mobileno"]]
= **{{extrude}}**
= 突出
[[/div]]
[[div class="content mobileno"]]
= **{{content}}**
= 正文
[[/div]]
[[div class="start-content-end extrude-end mobileno"]]
= **{{extrude}}**
= 突出
[[/div]]
[[div class="start-extrude-end fullwidth-end mobileno"]]
= **{{fullwidth}}**
= 全宽
[[/div]]

[[div class="fullwidth-start end-extrude-start mobileno" style="background: #eef7fe;padding: 0.6rem 0rem;font-size: 80%;"]]
= {{@@[[div class="fullwidth-start end-extrude-start"]]@@}}
[[/div]]
[[div class="extrude-start end-content-start mobileno" style="background: #dff1ff;padding: 0.6rem 0rem;font-size: 80%;"]]
= {{@@[[div class="extrude-start end-content-start"]]@@}}
[[/div]]
[[div class="content" style="background: #cee9ff;padding: 0.6rem 0rem;"]]
= {{@@[[div class="content"]]@@}}
[[/div]]
[[div class="start-content-end extrude-end mobileno" style="background: #dff1ff;padding: 0.6rem 0rem;font-size: 80%;"]]
= {{@@[[div class="start-content-end extrude-end"]]@@}}
[[/div]]
[[div class="start-extrude-end fullwidth-end mobileno" style="background: #eef7fe;padding: 0.6rem 0rem;font-size: 80%;"]]
= {{@@[[div class="start-extrude-end fullwidth-end"]]@@}}
[[/div]]


[[div class="extrude-start" style="background: #fff1ff;padding: 0.6rem 0rem;"]]
= {{@@[[div class="extrude-start"]]@@}}
[[/div]]
[[div class="extrude-end" style="background: #fff1ff;padding: 0.6rem 0rem;"]]
= {{@@[[div class="extrude-end"]]@@}}
[[/div]]
[[div class="extrude" style="background: #ffe6ff;padding: 0.6rem 0rem;"]]
= {{@@[[div class="extrude"]]@@}}
[[/div]]
[[div class="fullwidth-start" style="background: #eaeaff;padding: 0.6rem 0rem;"]]
= {{@@[[div class="fullwidth-start"]]@@}}
[[/div]]
[[div class="fullwidth-end" style="background: #eaeaff;padding: 0.6rem 0rem;"]]
= {{@@[[div class="fullwidth-end"]]@@}}
[[/div]]
[[div class="extrude-start fullwidth-end" style="background: #ffe5e5;padding: 0.6rem 0rem;"]]
= {{@@[[div class="extrude-start fullwidth-end"]]@@}}
[[/div]]
[[div class="fullwidth" style="background: #ddddff;padding: 0.6rem 0rem;"]]
= {{@@[[div class="fullwidth"]]@@}}
[[/div]]

这使得插入全宽元素更方便，但亦导致过氧化物无法正确显示裸文本布局（例如，使用换行而非空行可能会让Wikidot错误解析为裸文本而非块级元素{{<p>}}），CSS float也会失效。为取得最大兼容性，可将所有内容包裹在一个{{[[div]]}}内，或使用{{[[include :oxygennine:peroxide:layout-page-content-block]]}}取消这一特性。

++ 隐藏“Saving Pages”

在保存页面时，底部会出现一个“隐藏Saving Pages”的按钮。若遇到页面无响应，可点击此按钮，隐藏背景遮罩，将代码复制到安全的地方并刷新页面，重新编辑。
