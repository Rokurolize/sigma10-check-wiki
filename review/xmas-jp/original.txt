This is a theme originally created by [[*user Dc_Yerko]] for the [[[http://lafundacionscp.wikidot.com|Spanish Translation Site]]] and adapted by [[*user stormbreath]]. Code for the snow flakes adapted by [[*user EstrellaYoshte]].

Use it on your own article with the following:

[[div class="code"]]
@@[[include :scp-wiki:theme:xmas@@
@@|xmas-header= --]@@
@@|xmas-snow= --]]]@@
[[/div]]

If you only want to use the header, use the following:

[[div class="code"]]
@@[[include :scp-wiki:theme:xmas@@
@@|xmas-header= --]]]@@
[[/div]]

If you only want to use the snow, use the following:

[[div class="code"]]
@@[[include :scp-wiki:theme:xmas@@
@@|xmas-snow= --]]]@@
[[/div]]
