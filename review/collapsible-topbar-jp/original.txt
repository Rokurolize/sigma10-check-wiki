상단바를 한번 더 접어 숨기는 컴포넌트입니다. 테마 제작시 PC나 모바일 환경에서 상단바 항목이 너무 길어 불편이 있을 경우 사용하면 좋습니다. 사용하려는 문서에 아래 구문을 복사해 붙여넣으세요.

> @@[[include :scpko:component:collapsible-topbar]]@@

필요하다면 아래의 인수를 적절히 재선언해주세요.

* **maxw**
 * 이 값 이상의 화면폭을 가진 PC 환경에선 상단바를 접지 않습니다.
 * 767px ~ 10000px
 * 아래 인수들을 작동시키려면 maxw 인수를 수동 입력해야 합니다.
* **top-color**
 * 상단바를 펼치는 버튼의 텍스트 색상을 바꿉니다.
 * 기본값: #FFF
* **top-bg**
 * 펼쳐졌을 때 상단바의 배경 색상을 바꿉니다.
 * 기본값: 투명
[[/iftags]]

[[module CSS]]
.mobile-top-bar {
  max-width: 100% !important;
}

#top-bar {
  color: #FFF;
}

@media (max-width: {$maxw}) and (min-width: 768px) {
  #top-bar {
    visibility: hidden;
  }
  #top-bar > div > ul::before {
    content: "둘러보기";
    color: {$top-color};
    text-align: right;
    visibility: visible;
    display: block;
  }

  #top-bar:hover {
    width: 100%;
    visibility: visible;
    background-color: {$top-bg};
    border-left: 300px solid {$top-bg};
  }
  #top-bar:hover > div > ul::before {
    visibility: hidden;
    display: none;
  }
}

@media (max-width: 767px) {
  .mobile-top-bar {
    width: 100%;
  }

  #top-bar {
    visibility: hidden;
  }
  #top-bar .open-menu a {
    visibility: visible;
    display: block;
  }
  #top-bar > div > ul::after {
    content: "◀";
    color: {$top-color};
    text-align: right;
    visibility: visible;
    display: block;
  }

  #top-bar:hover {
    visibility: visible;
    width: 100%;
    background-color: {$top-bg};
    border-left: 300px solid {$top-bg};
  }
  #top-bar:hover > div > ul::after {
    visibility: hidden;
    display: none;
  }
}

@media (max-width: 385px) {
  .mobile-top-bar {
    width: 97%;
  }
}
[[/module]]

[[div style="display:none;"]]
[[include :scpko:component:collapsible-topbar maxw={$maxw}|maxw=10000px]]
[[/div]]
