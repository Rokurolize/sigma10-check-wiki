+ カスタマイズ

タイトルや背景を変更したい場合、またはサイト12ロゴのアニメーションを差し替えたい場合は……

テーマのincludeの後ろに次の記述を追加し、必要に応じて変更してください。

[[div style="text-align: left"]]
[[code type="css"]]
[[module css]]
:root {
    --header-title-text: "タイトル";
    --header-subtitle-text: "サブタイトル";

    --bg-img-mobile: url(https://url.com);
    /* モバイル用背景URL↑ */

    --bg-img: url(https://url.com);
    /* デスクトップ用背景URL↑ */

    --logo-img: url(https://url.com);
    /* 差し替え用ロゴURL↑ */

    --logo-anim: hidden;/* ←ロゴURLを差し替えた場合はhiddenを指定し、そうでなければこの行を削除 */
}
[[/module]]
[[/code]]
