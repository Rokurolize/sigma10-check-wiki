+ HOW TO USE?

To import this theme, simply add this snippet of code above your page and pray that I haven't fucked something up that would cause it to not work properly.
[[=]]
> [[include :scp-wiki:theme:black-highlighter-theme]]
> [[include :scp-wiki:theme:jakstyle]]
To edit the header, subheader, and background image, please use the following code after including the above:
[[/=]]
> [[module CSS]]
> :root {
>      @@--header-title: "title here";@@
>      @@--header-subtitle: "subtitle here";@@
>      @@--lgurl: url('your url here');@@
> }
> [[/module]]
**NOTE:** Please understand that this is a **DARK** theme. Attempting to edit this theme to use colors that are either really dark or immensely bright is probably going to hurt some eyes and hurt your total ratings (you'll thank me for this later.)
