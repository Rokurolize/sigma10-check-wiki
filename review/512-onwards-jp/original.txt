This is the Site-512 Theme by [[*user WaylandLaurencePan]], dubbed the 512 Onwards Theme. It is a [[[theme:basalt|Basalt]]]-based theme for [[[secure-facility-dossier-site-512|Site-512]]] and associated articles; in particular, the series [[[https://scp-wiki.wikidot.com/512-means-onwards-hub|512 Means Onwards]]] (did not exist as of writing; now exists as of reading). It shamelessly grabs CSS from [[[SCP-9628]]] by [[*user sprawlingstar]] (an incredible article, by the way).

It is wholly shaped by my personal preferences. Especially regarding the presence of ITEM#: in ACS and page titles.

Yes, it is an incredibly red theme. When your country's flag is dichromatic, there's only so much you can do.
[[toc]]

------

+ __Settings__

There are no easy buttons or dials, given this theme's intent to be used solely for Site-512 articles. Typical Basalt variables remain exposed. Modify CSS as needed. Feel free to contact me if you need help.

A few new variables have been added:
[[div class="blockquote"]]
 {{-​-onwards-ui-highlight: the highlight for the UI above
 -​-onwards-account-ui-selector: hover-color for account selector
 -​-onwards-header-sizing: customize the pattern size for the header
 -​-onwards-pattern-color1: first color for the pattern
 -​-onwards-pattern-color2: second color for the pattern
 -​-onwards-pattern-bgcolor: overall background color}}
[[/div]]
