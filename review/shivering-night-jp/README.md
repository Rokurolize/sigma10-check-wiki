## Summary

A large Sigma-9-lineage theme (1,622 original lines) whose delivery is a head module importing eight of its own code blocks, seven of them behind include-parameter gates that select header and layout variants. The port preserves that topology exactly: same module, same eight blocks in the same order and sizes, same gates in the same render-time position, with every address repointed to the candidate's own draft-host blocks. The substantive changes are the credit consolidation (the CN credit pair and its bare Rate become one preview credit block carrying the eight TASL fields and all six of the original's component and media attribution entries, translated), the CN-to-JP font substitution, the exhibit localization (including the six anomaly-class-bar exhibits), and the prose translation. Its one blocking item was a pair of dead prose links, re-derived below; the FIX5 lane's probe evidence also falsified the ledger's premise for the other two targets on the same line, and that exception is part of the record.
