# LOCALIZE-ROWS — T4/T5 verdict rows for the go-sign ledger

Extraction of T4 (localize-pattern + reference-revision follow-up) and T5 (translation-text) verdicts for every theme in the /start population (287 themes = 44 Stage-1 rows + 243 Stage-2 originals). Data extraction only — nothing in the canonical repo was edited and nothing was reflected. Source reports are the eight COMPLETE `REPORT-GOSIGN2-LOCALIZE-*.md` files in `R/`.

## How to read the columns

- **Theme fullname (candidate)**: the canonical port page. `theme:<slug>-jp` except `theme:quand-le-soleil-se-couche` (shared original+port page; no `-jp` file in the repo, per REPORT-GOSIGN2-LOCALIZE-B scope note and LEDGER §1.2) and `theme:sigma-10-jp` (REPORT-GOSIGN2-LOCALIZE-B row 37 candidate; the report names the original `theme:site`). amethyst-v2 has no candidate (named exception).
- **Source report**: the report whose per-theme section is the source of the verdict.
- **T4 verdict / T5 verdict**: the reports judge T4 and T5 jointly and state one combined verdict word per theme in their per-theme "Theme verdict"/verdict-tally; the reports do not emit separate T4-only and T5-only verdict words. Per the brief's rule ("If a fact you need is not in your scope sources, say so instead of inventing it"), both columns carry the report's own verdict word verbatim — PASS / FINDINGS / N/A (with reason). JP originals (min-theme, shushuin) are N/A (no translation); amethyst-v2 is N/A (named exception, no candidate).
- **Display-affecting findings (count)**: number of display-affecting MISSED/findings recorded in the theme's verdict line (or its explicit "Display-affecting MISSED" list). 0 for PASS/N/A.
- **Worst finding (one line)**: the report's own worst-finding statement from its per-theme verdict, trimmed to one line; `—` for PASS/N/A.
