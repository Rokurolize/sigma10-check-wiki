**How verdict cells were filled.** Each of the five reports emits a single *combined* T2/T3 verdict per theme (C/D/E/F: one `Verdict:` line; H: one `**Verdict:**` line with the T2/T3 split spelled out in its note). These five lanes judge in the vocabulary PASS / FINDINGS / BLOCKED-ENV / EXCEPTION, so the mapping applied is:
- report `FINDINGS` (≥1 render_check error line or T3 display finding) → **FAIL**;
- report `EXCEPTION` (no candidate/sample exists) → **NOT-RUN** (only amethyst-v2; the report's word is preserved in its findings cell).

No report issues a bare `PASS`, a `PASS-WITH-NOTES`-equivalent, or a per-theme `BLOCKED-ENV` — all 155 run themes are `FINDINGS`. Several T2 page/sample runs were inconclusive (exit 2 / no `summary.md` after retries); each such theme still carries the report's combined verdict, which is carried through, and the incompleteness is recorded in the findings rather than guessed into a NOT-RUN cell (the amethyst-v2 EXCEPTION is the only NOT-RUN). The report's own verdict word is preserved verbatim inside each findings cell.
