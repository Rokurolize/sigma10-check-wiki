# Owner rulings on the GOSIGN2 open questions (2026-11-16 19:20 JST)

Asked by the coordinator 19:09; answered by the owner 19:20. These govern adjudication of the
staff-skill sweep (T1-T5) and the GOSIGN2-LEDGER dispositions.

1. **Cross-theme CSS delivery (pattern 4).** A base theme (Basalt) cannot be used as-is in the
   Sigma-10 JP environment — that is why its JP port candidate, carrying the fixes, exists. If a
   dependent theme (e.g. Monotypical) imports the base's CSS from the original branch's delivery
   as-is, the fixes never reach it, and re-applying the same fixes inside every dependent theme
   is software-engineering nonsense. CONCLUSION (drawn by the coordinator from the owner's
   explanation, as invited): dependent themes' live code must import the base theme's JP port
   candidate delivery. Fix lane: BRIEF-GS-FIX-P4 (candela's bases are in the FIX2-INCLUDE scope).
2. **Header title in English (pattern 9, --header-title etc.).** OUT OF SCOPE for the Sigma-10
   migration correctness judgment: it is translation taste, case-by-case. English can be the
   design-correct choice; forcing Japanese can ruin a design. No blanket fix in either direction;
   pattern-9 findings of this kind are dispositioned out-of-scope in the ledger.
3. **Translator attribution (TASL).** A translation produced by Muse or its delegated agents is
   attributed 翻訳責任者: AI. A candidate that modifies someone else's existing translation must
   carry the explanation of that (adaptation note). What CC BY-SA 3.0 makes legally required must
   be recorded. Consequences: the ~211 candidates carrying 翻訳責任者: SCP-JP are corrected to AI
   (BRIEF-GS-FIX-CREDIT-D); human names are kept only where they match the live JP page's
   created_by; modified re-ports gain the adaptation line
   「**翻訳について:** <name> による既存の翻訳を基に改変したものです。」
4. **Components missing on JP (e.g. component:sigma-plus).** Porting the component is part of the
   theme's work, done together with the theme. "Block it while missing" is rejected — if nobody
   makes it exist, nothing moves; the coordinator is the one who moves. Canonical already carries
   component candidates (component:sigma-plus-jp, component:betterbetterfootnote-jp,
   component:navla-jp, component:rok-gov-base-jp, component:the-buck-stops-here-base-1-jp);
   per-theme dependency completeness is a ledger check.
5. **Basalt sample credit modal (T2 pilot finding).** Owner does not know either; the coordinator's
   investigation continues (render-lane cross-theme data + root-cause).
