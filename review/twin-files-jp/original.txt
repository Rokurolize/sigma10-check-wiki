++ What is this?
[[div class="blokquote-alt"]]
The Twin Files theme is a dark theme for BHL loosely visually based off of the aesthetics of the 90s television series //Twin Peaks// and //The X-Files//. You can use it for any article... but preferably one with an older-style, supernatural-adjacent government agency and investigation. Or if you like X-Files and Twin Peaks.

Any text not in the "dialog" table will show up centered. You can use this, for example, by having one dialog-class table, text saying "Log omitted for brevity", then another dialog-class table.

Make sure to use the "active" cell class for active dialogue. Hcell is for the speaker, and regular cells are for dialogue & action. One hcell per cell is a good rule, the only real exemption being for actions which don't need a speaker.
