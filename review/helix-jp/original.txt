+++ HELiX Technologies | LOGS > PUBLIC_LOGS > THEME > INFORMATION
------
This is a CSS theme for HELiX Technologies, an extraterrestrial genetic-biochemical engineering GoI, located on the exoplanet Kepler 22-b, in cooperation with the State of Kepler, most notably the Special Operations Division. Kepler 22-b is most notable for being the point of origin of [[[SCP-6118]]], a project by HELiX Technologies and the SGC Department.

The CSS HELiX Technologies theme was coded by [[*user tiredsn0w]] with logos created by tiredsn0w and an anonymous non-Wiki personnel. All images and text contained are CC BY-SA 3.0.

This theme was partially inspired by [https://scp-wiki.wikidot.com/component:croqstyle Croqstyle] by [[*user croquembouche]] and the [https://scp-wiki.wikidot.com/theme:pataphysics Pataphysics theme] by [[*user Lt Flops]]. The header is an edit of the Pataphysics header. Code has been borrowed from [https://scp-wiki.wikidot.com/akiva-counter-operating-instructions Akiva Counter Operating Instructions] by [[*user Jerden]].

The CSS HELiX Technologies theme is suitable for use on GoI formats, Tales, and HELiX-related documentation. It is a [https://scp-wiki.wikidot.com/theme:site Sigma-10]-based theme.
