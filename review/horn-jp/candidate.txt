+ これは何ですか？

これは[[*user nmscxj]]の[[[caromati|カルマティ（Caromati）]]]設定下の記事のために、[[*user hoah2333]]が制作した「号声」テーマです。
----
+ 使い方

作品の冒頭に次の構文を追加すると、このテーマを適用できます。

> [[include theme:horn-jp]]
----
ヘッダーを変更したい場合は、このテーマの変更方法がほかのテーマと少し異なる点に注意してください。上記のinclude構文の**後**に次の構文を追加すると、ヘッダーを変更できます。

[[div class="blockquote"]]
@@[[module css]]@@
#header {
@@    @@background: url('##2CC22C|@@https://scp-jp.wdfiles.com/local--files/theme%3Ablack-highlighter-theme/black-highlighter-logo.svg@@##') 10px 40px no-repeat;
@@    @@background-size: 100px 100px;
}
#header h1 a::before {
@@    @@content: "##FF4F4F|SCP財団##";
@@    @@color: ##7575FF|#EEFFFF##;
}
#header h2 span:before {
@@    @@content: "##FF4F4F|確保 収容 保護##";
@@    @@color: ##7575FF|#F0F0C0##;
}
@@[[/module]]@@
[[/div]]

##2CC22C|緑色の文字列##を変更するとヘッダーロゴを、##FF4F4F|赤色の文字列##を変更するとタイトル文を、##7575FF|青色の文字列##を変更すると対応する色を差し替えられます。
----
+ 例

[[include component:image-block name=https://scpsandboxcn.wikidot.com/local--files/nmscxj/%E6%9C%AA%E6%A0%87%E9%A2%98-1.jpg|caption=画像。|width=200px]]

5つのハイフン「@@-----@@」で水平線を作れます。引用ブロックなど、ほかの部品の中に置かれていなければ、ページ全体を左右に横切って伸びます。ファイルを複数の部分に分けるこうした線が水平線です。


見出しは、行頭に1個から6個のプラス記号「+」を入力して作成できます。
