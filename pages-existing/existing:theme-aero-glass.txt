[[[theme:monotypical| ]]]と同様に、このテーマは単なる一つのカラースキームを持つだけでなく、高い拡張性を備えたフレームワークを提供し、好みに合わせてあなただけのAero Glassテーマを作成できます。（詳しくは「DIY」セクションをご覧ください）

このテーマを使用するには、使用したい記事の冒頭に以下のコードを追加してください:

[[code type="CSS"]]

[[module CSS]]
:root {
    --title: " SCP財団";  /* ヘッダーのタイトル */
    --subtitle: " 確保 • 収容 • 保護";  /* ヘッダーのサブタイトル */
    --logo: url(https://scp-jp-storage.wdfiles.com/local--files/file%3A5722815-22-kg1l/basalt_logotype_darkmode.png);  /* ヘッダーのロゴ */

    --gray-monochrome: 38, 34, 66;  /* メインカラー */
    --dark-gray-monochrome: 29, 26, 56;  /* サブカラー、この変数には、メインカラーと同じ色合いで少し暗めの色を指定してください */

    --bright-accent: 203, 219, 250; /* リンクの色 */
    --pale-accent: 255, 75, 255; /* マウスオーバー時のリンクの色 */
    --newpage-color: 238, 212, 255;  /* 存在しないページへのリンクの色 */

    --background-image: url(https://scp-jp-storage.wdfiles.com/local--files/file%3A8260379-105-1ttu/bg-city.jpg);  /* 背景画像 */

    --main-aero-glass-filter: blur(7px) brightness(1);  /* 画面フィルター、明るい背景画像を使用した場合、白い文字が読みにくくなる可能性があるため、brightnessの値を小さくして輝度を下げることを推奨します */
}
[[/module]]
